# Yildiz Physiotherapy

This project is a modern landing page built for the Yildiz Physiotherapy clinic using Next.js and Tailwind CSS.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
